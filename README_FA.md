یک پیاده‌سازی کلاسیک و جذاب از بازی نوستالژیک **دوز (Tic-Tac-Toe)** در محیط کنسول و خط فرمان به زبان **پایتون (Python)**، مجهز به حریف کامپیوتری هوشمند با منطق پیش‌بینی حرکت و خروجی‌های رنگی ترمینال.

---

## نمای کلی پروژه

بازی دوز یک بازی دونفره فکری بر روی صفحه‌ای ۳ در ۳ است. هدف هر بازیکن رساندن ۳ مهره متوالی خود به یک خط مستقیم (افقی، عمودی یا مورب) است.

در این پیاده‌سازی، هوش مصنوعی رایانه تنها با حرکات تصادفی بازی نمی‌کند، بلکه دارای یک منطق استراتژیک سه‌مرحله‌ای است:
۱. **جستجوی حرکت پیروزی‌آور:** بررسی اینکه آیا رایانه می‌تواند در این نوبت فوراً بازی را ببرد.
۲. **دفاع و سد کردن حریف:** اگر کاربر در یک قدمی برد باشد، رایانه هوشمندانه آن خانه را تصاحب کرده و راه برد بازیکن را می‌بندد.
۳. **تصاحب موقعیت‌های استراتژیک:** در صورت نبود موقعیت برد یا باخت فوری، رایانه اولویت را به خانه‌های باارزش گوشه و مرکز اختصاص می‌دهد.

---

## ویژگی‌های کلیدی

- **هوش مصنوعی استراتژیک:** الگوریتم تصمیم‌گیری پیشگیرانه و دفاعی برای رایانه.
- **رابط متنی رنگی و خوانا:** استفاده از کتابخانه `termcolor` برای نمایش مهره‌های کاربر با رنگ قرمز (`[X]`) و رایانه با رنگ آبی (`[O]`).
- **صفحه‌کلید عددی ساده:** کنترل ساده بازی با فشردن شماره‌های ۱ تا ۹ مطابق با چیدمان NumPad.
- **اعتبارسنجی ورودی‌ها:** جلوگیری از درج کاراکترهای نامعتبر یا خانه‌های از پیش پر شده.

---

## راهنمای بازی

خانه‌های صفحه دوز با شماره‌های **۱ تا ۹** مشخص شده‌اند:

```text
[1] [2] [3]
[4] [5] [6]
[7] [8] [9]
```

۱. شما بازیکن **X** (قرمز) هستید و شروع‌کننده بازی خواهید بود.
۲. کامپیوتر با مهره **O** (آبی) پاسخ خواهد داد.
۳. در هر نوبت، شماره خانه خالی مدنظر خود را وارد کنید.
۴. بازیکنی که بتواند سه علامت خود را در یک سطر، ستون یا قطر پیوند دهد، برنده اعلام می‌شود!

### پیش‌نیازها

- پایتون نسخه ۳.۷ یا بالاتر
- کتابخانه `termcolor`

### مراحل اجرا

۱. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/soheilabbasnia/tic-toc-toe.git
   cd tic-toc-toe
   ```

۲. **نصب وابستگی:**
   ```bash
   pip install termcolor
   ```

۳. **اجرای بازی:**
   ```bash
   python3 program.py
   ```
